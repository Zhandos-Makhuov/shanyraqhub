# Phase 2.4.1 — Physical Mobile QA (форум и закрытые комнаты)

Устройство: Android-смартфон владельца (Samsung), Chrome. Сайт: демо https://shanyraq-demo-auto.pages.dev (ветка `claude/sleepy-brown-4zolp6`, коммит `6a5d38b`; данные демо хранятся только в браузере телефона). Боевой сайт и превью ветки не использовались.

Статусы: **PASS** — подтверждено владельцем на телефоне; **FAIL** — дефект на телефоне; **BLOCKED** — нельзя проверить; **NOT TESTED** — ещё не проверено; **CODE VERIFIED** — только по коду/автопроверкам (не физически). Физически проверена одна ширина экрана (телефон владельца); остальные ширины покрыты только автопроверками.

## Наблюдения
- **A9 / системный «назад».** Сайт — одностраничное приложение без истории переходов: разделы, открытая тема и окна — внутреннее состояние страницы, в историю браузера ничего не записывается. Поэтому «назад» Android уходит на предыдущий сайт. Это существующее устройство всего приложения (не только форума), не дефект Phase 2.4.1. **Решение владельца 23.11.2026:** отдельным этапом для всего сайта; записано в бэклог (N-4, DEFERRED).
