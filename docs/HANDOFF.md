## 5. Как работать (проверенные команды)
- **Сайт:** `bun install`; `bun run lint`; `bun run build`; `VITE_DATA_SOURCE=live npx vite build --outDir <scratch>` (в боевой нет демо-имён); `bun run test:e2e -- --trace off` (сам собирает `dist-e2e`, ≈2 мин).
- **`.env.local`** (тестовый проект, в `.gitignore`, в новом контейнере создать заново) — публичные значения в `CLAUDE.md`, этап 5 (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_VAPID_PUBLIC_KEY`).
- **База** (токен Management API подставляет прокси среды; в код и чат не класть; из скриптов — только `curl`, Node `fetch` не идёт через прокси):
  ```bash
  out=$(python3 supabase/tests/run-cloud.py dryrun 2>&1); echo "$out" | tail -c 300   # тестовая: новые миграции + все проверки, с откатом
  echo "$out" | grep -q '^passed=' && SUPABASE_PROJECT_REF=fwhcaspbbktgpjiskpln python3 scripts/apply-migrations.py
  python3 supabase/tests/run-cloud.py tests && python3 supabase/tests/run-cloud.py lint
  SHQ_TEST_PASSWORD=<пароль> python3 supabase/tests/api-access.py                       # только тестовая база
  ```
  Боевая — `SUPABASE_PROJECT_REF=gqxdridlxlnouqseeyno`, **только с согласия владельца**. Не строить цепочки `dryrun | tail && apply` (`tail` скрывает код ошибки).
- **Тестовые аккаунты** (тестовая база): `claude-test@shanyraq-hub.test` (member), `claude-org@shanyraq-hub.test` (organizer), `tg-7000000001/2/3@telegram.invalid` (без пароля, только для SQL). Пароль нигде не хранится — в новом контейнере задать заново: `update auth.users set encrypted_password = extensions.crypt('<новый>', extensions.gen_salt('bf')) where email in ('claude-test@shanyraq-hub.test','claude-org@shanyraq-hub.test');` и держать в scratchpad (`pw.txt`).
- **Особенности базы:** `events.created_by` ставит база (триггер) — встречи для тестов создавать от имени организатора (`set_config('request.jwt.claims', …)` + `set local role authenticated`), а не служебным SQL; форма встречи требует ≥5 мест; файлы хранилища удалять только через Storage API.
- **Браузерные проверки:** Playwright (`require('playwright')`, Chromium предустановлен), скрипты — в scratchpad. Демо-сборка на 4185 (`npx vite preview --outDir dist-e2e`), live-сборка на 3001 (`VITE_DATA_SOURCE=live npx vite --port 3001`). axe-core — в scratchpad (`npm i axe-core` в отдельной папке). Разделы сайта грузятся отдельными файлами — в проверках ждать исчезновения `[data-view-loading]` (это делает `goTab` в `e2e/fixtures.ts`).
- **GitHub:** только MCP-инструменты (`mcp__github__*`, загружать через ToolSearch); PR не создавать без просьбы.
