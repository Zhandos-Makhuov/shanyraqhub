## 3. Как работать (проверенный порядок)
- Сайт: `bun run lint`, `bun run build`, `VITE_DATA_SOURCE=live npx vite build` (нет демо-имён).
  `.env.local` (тестовый проект) в новом контейнере создать заново — значения в `CLAUDE.md`, раздел этапа 5.
- База (токен Management API подставляет прокси среды, в код и чат не класть):
  ```bash
  python3 supabase/tests/run-cloud.py dryrun          # тестовый проект: новые миграции + все проверки, с откатом
  SUPABASE_PROJECT_REF=fwhcaspbbktgpjiskpln python3 scripts/apply-migrations.py
  python3 supabase/tests/run-cloud.py tests && python3 supabase/tests/run-cloud.py lint
  ```
  Боевой — то же с `SUPABASE_PROJECT_REF=gqxdridlxlnouqseeyno`, **только с согласия владельца**.
- **Применять миграцию в боевую — только если пробный прогон напечатал `passed=…`.** Не строить цепочки
  `dryrun | tail && apply`: `tail` скрывает код ошибки (так 20.11 миграция применилась после неудачного прогона —
  без вреда, но правило такое):
  ```bash
  out=$(python3 supabase/tests/run-cloud.py dryrun 2>&1); echo "$out" | tail -c 300
  echo "$out" | grep -q '^passed=' && python3 scripts/apply-migrations.py
  ```
- Проверки (`supabase/tests/security_tests.sql`) должны работать и на непустой базе: счётчики — относительно
  исходных, направления открываются только внутри откатываемой транзакции, «последний супер-админ» — только если он один.
- Edge Functions выкладываются через Management API (`/functions/deploy?slug=…`, multipart, `verify_jwt=false`);
  типы проверять Deno (`npm i deno` в scratchpad, `deno check` с `nodeModulesDir: auto`).
- Слияние в `main`: `git push origin claude/sleepy-brown-4zolp6:main` — **каждый раз с согласия владельца**.
  Система разрешений среды иногда блокирует эту команду — тогда остановиться и спросить владельца, не обходить.
- Браузерные проверки: Playwright, скрипты в scratchpad. На ширине телефона кнопки нижнего меню — `nav button:visible`.
  Тестовые аккаунты (тестовый проект): `claude-test@shanyraq-hub.test` (member), `claude-org@shanyraq-hub.test`
  (organizer; для проверок временно повышать и возвращать роль). Пароли — только в scratchpad, в новом контейнере
  задать заново SQL-запросом (см. `CLAUDE.md`, этап 5).
