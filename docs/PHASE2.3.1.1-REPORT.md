## 1. Telegram в чужом профиле
- `MemberProfileModal.tsx`: показан Telegram участника, если он указан; рядом @handle со своим значком (человек) — Telegram со значком Telegram и другим цветом. Подписи «Telegram» / «Клубтағы есім · Имя в клубе · Club handle» — для скринридера и во всплывающей подсказке. Длинные значения переносятся (`break-all`).
- Пустое значение — блок не показывается.
- Общий компонент `TelegramContact` (`ProfileParts.tsx`) — в своём и чужом профиле одинаково.
- **Ссылка** `https://t.me/<username>` строится только если значение — корректный username Telegram (`^@?[A-Za-z][A-Za-z0-9_]{4,31}$`, функция `telegramUsername`); открывается в новой вкладке с `rel="noopener noreferrer"`. Любой другой текст показывается простым текстом, URL из него не создаётся (проверено на `javascript:alert(1)`).
- Телефон, почта, внутренние id не показываются (проверяется e2e).

## 2. Доступность вкладок профиля (`ProfileView.tsx`)
- Roving tabindex: в порядке Tab только выбранная вкладка (`tabIndex=0`), остальные `-1`.
- ← / → — соседняя вкладка (по кругу), Home / End — первая / последняя; вкладка выбирается и получает фокус, лента прокручивается так, чтобы она была видна целиком.
- У вкладок `id="prf-tab-…"` и `aria-controls="prf-panel-…"`; у панелей `role="tabpanel"`, `id="prf-panel-…"`, `aria-labelledby="prf-tab-…"`; все 4 панели есть в разметке, неактивные — `hidden` (содержимое рисуется только у выбранной).
- Мышь и касание работают как раньше; горизонтальная прокрутка ленты на телефоне сохранена.
