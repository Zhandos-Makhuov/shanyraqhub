## 2. Что изменено
- **Profile Overview** — в своём профиле и в окне участника одинаковый порядок: шапка → **«Деңгей прогресі»** + **«Соңғы жетістіктер»** (две панели рядом на широком экране, друг под другом на телефоне) → прежние разделы.
- Блок «Коины / Клуб тәжірибесі» в шапке своего профиля заменён панелью прогресса (XP и коины — в ней, без дублей).
- Окно участника: XP перенесён из строки контактов в панель прогресса (без коинов); добавлена дата вступления (как в своём профиле); полный список достижений участника сохранён и открывается кнопкой «Барлығы (n)».
- Общие компоненты (`ProfileParts.tsx`): `TierProgressPanel`, `RecentAchievements`; расчёты — `src/utils/profileProgress.ts` (`tierProgress`, `recentAchievements`, `activeAchievementCount`).
- Live-адаптер: достижения участника идут в порядке получения (по времени из базы), чтобы «последние» были точными и внутри одного дня. Состав достижений не менялся.
- 7 новых ключей перевода × 3 языка.

## 4. Новая структура профиля
**Свой профиль:** шапка (аватар с экипировкой, имя, уровень, роль, био, город, @handle, Telegram, дата вступления, направления, «Профильді өңдеу») → обзор: «Деңгей прогресі» (с коинами) | «Соңғы жетістіктер» (+ «Барлық жетістіктер →») → вкладки (книги, посещения, награды, отзывы) — без изменений.
**Окно участника:** шапка (аватар, имя, уровень, роль, био, город, @handle, Telegram, дата вступления) → направления → обзор: «Деңгей прогресі» (без коинов) | «Соңғы жетістіктер» (+ «Барлығы (n)», если их больше 3) → полный список достижений (по кнопке) → книги → отзывы и форма отзыва — как раньше.
Длинные имя и био переносятся; карточки не шире экрана (проверено e2e).

## 5. Gamification
- Данные только из существующей системы: XP участника и пороги `TIERS` (в live — из базы). Уровень по-прежнему определяет `tierForXp`; пороги и начисление не менялись.
- Показывается: название текущего уровня, «XP / порог следующего уровня», полоска, «“<следующий>” деңгейіне дейін N XP қалды».
- Процент — целый, вниз (`floor`), всегда 0–100: 299/300 XP — 99 %, а не ложные 100 %; отрицательный/пустой XP — 0 %; на последнем уровне (Тәңір) — полная полоска, без «/ порог», текст «Ең жоғары деңгейге жеттіңіз 👑» (у другого участника — «Ең жоғары деңгей 👑»).
- Полоска: `role="progressbar"`, `aria-valuenow/min/max`, подпись «Келесі деңгейге дейінгі прогресс».
- Коины — только в своём профиле (модель A); в окне участника коинов нет (проверено e2e и на тестовой базе).

## 6. Последние достижения
- До 3 последних полученных, новые сверху: по дате получения, при одной дате — по порядку получения.
- Отозванные не показываются: в live их нет в `user_achievements` (сервер удаляет), а дополнительно отбрасываются id из `revokedAchievementIds` (если когда-то окажутся в списке).
- Для каждого: иконка, название на языке интерфейса, «22 қар. 2026 алынды» (день по Алматы).
- Пусто: свой — «Мұнда сіздің жетістіктеріңіз пайда болады — клубтың жақын кездесуінен бастаңыз»; чужой — «Әзірге алынған жетістік жоқ.».
- Переход: свой — «Барлық жетістіктер →» открывает существующий экран «Жетістіктер»; в окне участника экран «Жетістіктер» показывает **свои** достижения, поэтому там вместо перехода — «Барлығы (n)», раскрывающий существующий полный список этого участника.
- Это не витрина: выбора, закрепления, порядка, `profile_showcase`, миграций и RLS нет.
