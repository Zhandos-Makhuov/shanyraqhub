# Phase 2.4 — Forum Audit: краткий отчёт для ChatGPT

Дата: 22.11.2026. Ветка `claude/sleepy-brown-4zolp6`. Полный документ — `docs/PHASE2.4-FORUM-AUDIT.md`.

## Executive summary
«Форум және Чаттар» — один экран `src/components/ForumAndChatsView.tsx`: темы с ответами и голосами + закрытые комнаты (чат по ролям). Базовые сценарии работают, сервер хорошо защищает экономику и модерационные поля (триггеры + RLS). Проблемы — в интерфейсе: создание темы ломается для части направлений, ошибки стирают текст, на телефонах обрезана кнопка ответа, темы не открываются с клавиатуры, текст постов теряет абзацы и обрезает длинные слова; роли и даты не локализованы; модерации в UI нет.

**Итого: 32 замечания** — Critical 0, **High 5**, **Medium 14**, **Low 13**; **2 Security concerns** (Low, нужно решение владельца).

## Главные проблемы
1. **F-01 (High, Verified на тестовой базе):** тему в «Нетворкинг» и любых новых направлениях создать нельзя — нет раздела форума (`forum_categories`), сервер отклоняет, «Енгізілген деректерді тексеріңіз», текст потерян.
2. **F-02 (High, Verified):** ошибка при создании темы/ответа стирает набранное; нет индикатора отправки и клиентских лимитов (заголовок из 2 символов отклоняется сервером).
3. **F-03 (High, Verified):** кнопка «Жауап беру» обрезана на 320–390 px (на 320 — на 71 px).
4. **F-04 (High, Verified):** карточки тем и комнат — `div`, с клавиатуры не открыть.
5. **F-05 (High, Verified):** абзацы склеиваются, длинные слова/ссылки обрезаются.
