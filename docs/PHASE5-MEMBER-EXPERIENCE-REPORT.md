## 1. Executive summary
Проблема: обычный участник, открывая сайт, видит в основном **встречи**. Книги, которые он читает, и обсуждения, в которых он участвует, с главной не видны. Нет списка «на что я записан». На форуме не найти «свои» темы. Новичку не объяснено, с чего начать (например, что направление выбирается заявкой в профиле). Вклад участника в клуб нигде не собран.

Сделано одним блоком, только из уже имеющихся данных, без миграций и без новых наград:
1. **Главная → «Жалғастыру» (Продолжить):** книги «Оқып жатырмын» (открывают окно книги), мои обсуждения, где после моего последнего сообщения ответили другие (открывают тему), кнопки «Менің жазылуларым: N» и «Менің талқылауларым: N».
2. **Главная → «Клубтағы алғашқы қадамдар» (Первые шаги)** для новичка: 5 шагов (о себе, направление, встреча, книга, форум), отметки — по настоящим данным, без наград; можно скрыть; исчезает после первого подтверждённого посещения или когда всё сделано.
3. **Встречи → чип «Менің кездесулерім»:** только встречи, на которые я записан или где был.
4. **Форум → «Менің талқылауларым»** в списке разделов + метка «Сізден кейін N жауап» на карточке темы.
5. **Профиль → «Клубқа қосқан үлесім» (Мой вклад):** посещения, прочитанные книги, рецензии, темы и ответы на форуме, отзывы о встречах — всего и «осы айда +N».
6. Попутно: счётчик уведомлений в шапке — контраст 3,19:1 → ≈5:1 (найдено axe на тестовой базе).

Проверки: e2e **218/218** (201 прежних + 17 новых), lint, демо- и боевая сборки (в боевой нет демо-имён), axe (WCAG A/AA) по новым блокам — 0 нарушений, live на тестовой базе (9 проверок), API **41/41**, серверные тесты **269/269** (регрессия).

## 3. Выбранный объём и обоснование
**Делаем (одним потоком):** P5-1, P5-2, P5-3, P5-4, P5-5 и попутно P5-6. Все — на существующих данных и экранах, без миграций, без новых сервисов, без изменения правил наград; каждое ведёт к уже существующему действию (окно книги, тема, встреча, профиль).
**Не делаем:** P5-7, P5-8 (нужны миграции и решение владельца), P5-9 (мало данных), P5-10 (решение владельца по приватности), соревновательные механики (серии/очки за заход — противоречит принципу «без накруток»).
**Зависимости:** нет (база не меняется). **Риски:** см. раздел 15.

**Критерии приёмки:**
- главная показывает «Жалғастыру», только если есть что продолжить; каждая строка открывает именно эту книгу/тему; «мои записи» открывают встречи с включённым фильтром;
- «Первые шаги» — только для новичка (нет подтверждённого посещения), отметки — по настоящим данным, можно скрыть (сохраняется после перезагрузки);
- фильтр «Менің кездесулерім» — записан или был; пустой — с понятной подсказкой;
- «Менің талқылауларым» — темы, где я автор или отвечал; «Сізден кейін N» — только ответы других после моего последнего сообщения;
- «Мой вклад» — те же правила подсчёта, что в остальном сайте (посещение = подтверждённое); у новичка — строка-подсказка, без нулевых плиток;
- kz/ru/en, 320–1280 px без горизонтальной прокрутки, axe без нарушений, все прежние проверки зелёные.

- Демо-форум содержит даты 2024 г., поэтому «осы айда» в демо по форуму пусто — в live считается по настоящим датам (проверено).
