## 1. Кратко
- **Окна стали доступными:** окно книги и форма — с названием для скринридера, фокусом внутри, Escape и возвратом фокуса на карточку; подписи связаны с полями.
- **Форма больше не теряет рецензию:** закрывается только после того, как сервер сохранил запись. При ошибке форма остаётся открытой с набранным текстом, а ошибка видна внутри (раньше форма закрывалась сразу, показывался `alert`, текст пропадал).
- **Меньше дублей:** пока участник вводит название, форма показывает похожие книги клуба (регистр, ё/е, кавычки не важны). Кнопка «Осы кітап» добавляет запись к существующей книге.
- **«Сөреден алу»:** ошибочно добавленную книгу со статусом «Оқып жатырмын» можно убрать (с подтверждением). Прочитанную — нельзя, она могла быть засчитана (S-3).
- **Книга → форум:** кнопка «Форумдағы талқылаулар» открывает форум с поиском по названию книги, пояснением и кнопкой «Осы кітап туралы тақырып ашу» (раздел «Кітаптар», заголовок уже заполнен). При повторном переходе находится уже созданная тема, поэтому второй не нужно.
- **Обложки:** проверено на настоящей обложке из каталога. В сетке почти ничего не срезается; в окне книги обложка теперь видна целиком.
- **Мелочи:** пустой каталог показывает своё состояние вместо «ничего не найдено», у кнопки-значка «Добавить» появилось имя, оценка только для прочитанных, подписи поиска и сортировки, аватары с запасным видом, контраст.
- **Backend не менялся.** Найдена проблема безопасности **S-3** — она уже есть в API, интерфейс её не открывает; нужно решение владельца.
- **Проверки:** lint ✅, сборки ✅, e2e **160/160** (+18 новых), axe 0 нарушений, на **тестовой** базе **16/16**. Статус CI — в сообщении в чате.
- **Готово к независимому ревью.**

## 5. Технические решения
1. **Без миграций.** «Хочу прочитать», «Книга месяца», описание, связь темы с книгой по id, объединение дублей требуют изменения схемы или RPC, поэтому записаны как DEFERRED. Сделано то, что позволяет текущая база.
2. **Сохранение с результатом.** Добавлена `saveReadBook`: она возвращает `{ok, credited, error, coverError}`. Прежняя `addReadBook` оставлена без изменений для совместимости.
3. **Подсказка вместо запрета.** Похожие книги только предлагаются: участник может осознанно добавить другую книгу с похожим названием. Совпадение считается по названию без учёта регистра, ё/е и знаков препинания (точное совпадение или вхождение от 4 символов).
4. **«Сөреден алу» только для «Читаю».** Удаление прочитанной записи освобождает недельный зачёт (S-3), поэтому интерфейс его не предлагает. Логика проверяет то же, а запрос к базе содержит `status = 'reading'`.
5. **Книга → форум без связи в базе.** Используется готовый поиск форума (Phase 2.4.2): защита от дублей тем — пользователь сначала видит найденные темы. Заголовок новой темы — «Название» — Автор, чтобы её находил следующий переход.
6. **Обложка.** В сетке оставлена рамка (3:4 на телефоне, 2:3 шире): все карточки одной высоты, а на настоящей обложке срезается ≈2–4%. В окне книги — вся обложка в своих пропорциях.

**S-3 (безопасность, найдено при аудите кода; на базе не воспроизводилось):** правило «одна засчитанная книга в неделю» в `save_user_book` смотрит на **оставшиеся** записи. RLS `user_books_delete_own` позволяет участнику через API удалить свою прочитанную запись, после чего можно получить +50 XP / +30 коинов за другую книгу в ту же неделю (каждая книга — один раз). Интерфейс этого не позволяет. Варианты исправления: запретить удаление `completed` в RLS или считать неделю по `reward_ledger`. Нужна миграция и отдельное согласие.

## 6. Обложки: проверка на настоящих данных
- Боевой каталог (только чтение `books`: название, автор, наличие обложки): **1 книга**, «Волоколамское шоссе», обложка 432×600 (0,72). Тестовый каталог: 9 книг, 5 обложек (400×600).
- Сетка, телефон (3:4 = 0,75): срезается ≈2% сверху и снизу — название и автор на обложке видны (скриншоты 320/390). От 480 px (2:3): ≈3,7% по бокам.
- Окно книги: обложка целиком в своих пропорциях — e2e на 8 ширинах (432×600 → 1,39) и на тестовой базе (настоящая загруженная обложка 400×600 → 1,50).
- Ограничение: выборка маленькая. Проверку стоит повторить, когда обложек станет больше.
